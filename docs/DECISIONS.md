## 2026-11-25: CPU-экология и GPU-рендер

**Контекст:** Нужна реальная наследственность, мутации и предсказуемая экосистема, но при этом выразительная графика без зависимостей.

**Решение:** Детерминированную симуляцию считать на CPU на typed arrays с двойной буферизацией. WebGL2 использовать только для процедурного рендера бумаги, клеток, климата и сезонных красок. При отсутствии WebGL2 работает Canvas 2D fallback.

**Альтернативы:** Полностью GPU-симуляция быстрее на больших сетках, но усложняет тестирование, атомарность обновлений и отладку мутаций.

**Trade-off:** CPU ограничивает размер сетки, зато логика остаётся тестируемой через один публичный seam и одинаково работает во всех браузерах.

## 2026-11-25: Conway как базовый слой трофической сети

**Контекст:** Пользователь просил клеточный автомат Конвея, но простые B3/S23 не дают эволюции, хищников и паразитов.

**Решение:** Продуценты подчиняются классическим B3/S23. Высшие трофические уровни используют соседские взаимодействия, энергию, наследственные признаки и мутации. Мутации меняют пороги размножения, устойчивость и пищевые стратегии.

**Альтернативы:** Отдельный режим классической Игры Жизнь; полностью независимые правила для каждого вида.

**Trade-off:** Экосистема не является чистой формой Conway, зато сохраняет его базовый паттерн и добавляет биологический отбор.

## 2026-11-25: Бумажная визуальная система

**Контекст:** Предыдущая неоновая арена оказалась жанрово шаблонной.

**Решение:** Использовать палитру натуралиста: тёплая бумага, тушь, мох, охра, ржавчина и багрец. Формы клеток рисуются как органические штампы и акварельные пятна, без неонового свечения.

**Альтернативы:** Тёмная научная визуализация; пиксельный ретро-стиль.

**Trade-off:** Меньше « sci-fi» эффектов, зато узнаваемая авторская айдентика и сильный контраст с прошлой игрой.
