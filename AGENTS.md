# GameHungerGEvo — инструкции для агентов

## Команды

- Запуск: открыть `index.html` в браузере. Сборка и сервер не нужны.
- Проверка: `node scripts/check-evo.cjs`.
- Длинная проверка: `node scripts/check-evo.cjs --long` — два seed по 10 лет.
- Ручной сценарий: новая колония → рисование жизни → смена сезона → паразиты → хищники → редуценты → мутации.

## Конвенции

- Vanilla HTML/CSS/JavaScript, без зависимостей, CDN и сетевых запросов.
- Вся игра находится в `index.html`; `scripts/` содержит только проверки.
- Детерминированная CPU-симуляция на typed arrays; WebGL2 используется только для рендера.
- Сетка 180×100, фиксированный шаг симуляции 1/12 секунды.
- Геном организма — шесть наследственных признаков; мутации происходят при размножении.
- Классическое правило Conway B3/S23 применяется к продуцентам; остальные уровни трофической сети имеют экологические правила.
- Заголовки и интерфейс — обычный регистр.

## Структура

- `index.html` — разметка, стили, экосистема, WebGL2/Canvas-рендер, UI и управление.
- `scripts/check-evo.cjs` — синтаксическая, экологическая и эволюционная проверка без фреймворков.
- `docs/CONTEXT.md` — состояние, глоссарий и журнал.
- `docs/DECISIONS.md` — архитектурные решения.
